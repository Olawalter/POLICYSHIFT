# POLICYSHIFT

GenLayer-native policy-change adjudication: immutable policy-version lineage, criteria frozen before evidence, and three separately validated assessments (change, applicability, compliance) in one Intelligent Contract with a Next.js frontend.

**Status: built and logic-tested locally against a test double; NOT linted, NOT deployed, NOT run on Studio.** See `docs/TEST_REPORT.md` before claiming anything more.

```
contracts/policyshift.py            the Intelligent Contract
contracts/_bad_leader/              generated by scripts/make_bad_leader.py (integration tests only)
docs/                               PROTOCOL_SPEC, CONTRACT_SPEC, EVIDENCE_MODEL, VERIFICATION_DESIGN, FRONTEND_SPEC, TEST_REPORT
tests/direct/                       local logic tests (stub harness)
tests/integration/                  Studio tests + fixtures (blocked until run on a real environment)
frontend/                           Next.js app (all chain calls in lib/chain.ts)
```

## Run the local logic tests
`python3 -m unittest tests/direct/test_policyshift_logic.py`

## Next steps on a machine with the GenLayer toolchain
1. Install the official dev plugin/skills (`/plugin marketplace add genlayerlabs/skills`, `/plugin install genlayer-dev@genlayerlabs`) and the CLI; start Studio with an LLM provider configured.
2. `genvm-lint` on `contracts/policyshift.py`; fix findings; confirm line-1 runner hash.
3. Deploy to StudioNet, record the real address and deployment tx hash.
4. Host `tests/integration/fixtures/*.txt` at stable https URLs; set `POLICYSHIFT_URL_V1/V2/EVIDENCE`; run `tests/integration`; deploy the bad-leader build and show rejection.
5. `cd frontend && cp .env.example .env.local` (set the address) `&& ./setup.sh && npm run dev`.

## Design in one paragraph
Validators do not just compare outputs. Each one re-fetches the digest-committed sources, re-runs the assessment, verifies every quote the leader cited against its *own* retrieved text, re-applies deterministic temporal/consistency rules, and only then compares decision fields. Retrieval or format failures raise errors and change no state; they never become verdicts. See `docs/VERIFICATION_DESIGN.md`.
